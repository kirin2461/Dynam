## Zone A — DPI Core & Packet Interception

**Files**: `ncp_dpi.cpp`, `dpi_advanced.cpp`, `ncp_dpi_zapret.cpp`, `ncp_packet_interceptor.cpp`

| ID | Issue | Status |
|----|-------|--------|
| **R16-A01** | `stop()` deadlock in WinDivert mode | ✅ Fixed |
| **R16-A02** | Linux NFQUEUE driver-mode silently stubbed | ✅ Fixed (honest failure) |
| **R16-A03** | SNI offset misinterpreted → hostlist/selective desync dead | ✅ Fixed |
| **R16-A04** | XOR_ROLLING deobfuscate used dead rx-counter | ✅ Fixed |
| **R16-A05** | Double bind of port 8881 in PROXY+advanced | ✅ Fixed |
| **R16-A06** | Zapret hostlist: filename matched as hostname | ✅ Fixed |
| **R16-A07** | No half-close propagation in PROXY mode (thread/slot leak) | ✅ Fixed |
| **R16-A08** | WFP `inject_packet` (WDK) incorrect NDIS usage | ✅ Fixed |
| **R16-A09** | Minor: size_t underflow, unimplemented flags, config data race | ✅ Fixed |

**Fix Details**:

#### R16-A01: stop() Deadlock (WinDivert)
- `cleanup_windivert()` (`WinDivertClose` on both handles) now runs **before**
  joining worker threads — blocked `WinDivertRecv` calls return and threads exit.

#### R16-A02: NFQUEUE Driver Mode — Honest Failure
- Linux NFQUEUE driver-mode desync was a silent stub (no iptables rule installed,
  no desync performed). Now returns a clear, explicit error instead of pretending
  to work. Full implementation is on the roadmap (see Remaining Risks).

#### R16-A03: SNI Offset Misinterpretation
- `windivert_loop` treated the return value of `find_sni_hostname_offset` as the
  position of the length field → hostlist and selective desync were effectively
  dead. Fixed in the calling code.

#### R16-A04: XOR_ROLLING Deobfuscation Counter
- The rx-counter was zeroed and never read (tx counter was used instead).
  A real rx-counter is now maintained.

#### R16-A05: Double Bind on Port 8881
- In PROXY+advanced mode the internal `base_only` listener no longer starts,
  eliminating the double bind.

#### R16-A06: Zapret Hostlist Loading
- Implemented `load_hostlist`: file → `HostlistMatcher` with exact/subdomain/wildcard
  matching and caching. Previously the *filename itself* was matched as a hostname.

#### R16-A07: Half-Close Propagation (PROXY mode)
- Peer `shutdown()` is now propagated on EOF — relay threads and connection slots
  no longer leak.

#### R16-A08: WFP inject_packet (WDK)
- Correct `NdisGetDataBuffer` usage (`PUCHAR`) and a real
  `NdisAllocateNetBufferListPool` instead of placeholder logic.

#### R16-A09: Minor Fixes
- `size_t` underflow in jitter computation.
- `split_at_midsld` / `autottl` flags actually implemented.
- `apply_chain_overrides` now preserves `split_positions`.
- Config data race eliminated via snapshot under mutex.

## Zone B — Security, License, E2E, ECH

**Files**: `security.cpp`, `license.cpp`, `e2e.cpp`, `ncp_ech.cpp`, `ncp_ech_cache.cpp`, `ncp_probe_resist.cpp`, `ncp_identity.cpp`

| ID | Issue | Status |
|----|-------|--------|
| **R16-B01** | UAF: `X509_digest` after `X509_free` | ✅ Fixed |
| **R16-B02** | License online-validation MITM (no hostname check) | ✅ Fixed |
| **R16-B03** | e2e key export/import unimplemented | ✅ Fixed |
| **R16-B04** | ECH HPKE double-encap pattern | ✅ Fixed |
| **R16-B05** | Inconsistent certificate pin formats | ✅ Fixed |
| **R16-B06** | `probe_resist::verify_auth` OOB read (auth_length < 32) | ✅ Fixed |
| **R16-B07** | e2e truncated transcript-hash response accepted | ✅ Fixed |
| **R16-B08** | `check_memory_integrity` was a stub | ✅ Fixed |
| **R16-B09** | ech_cache v1 format + OOM via domain_len | ✅ Fixed |
| **R16-B10** | `create_test_ech_config` used zeroed X25519 key | ✅ Fixed |
| **R16-B11** | `ratchet_dh` accepted wrong-size peer keys (protocol confusion) | ✅ Fixed |
| **R16-B12** | identity rotation semantics/statistics dishonest | ✅ Fixed |

**Fix Details**:

#### R16-B01: X509 Use-After-Free
- Digest is now computed **before** `X509_free`. Bonus: the whole block was dead
  due to `#ifdef OPENSSL_VERSION` (correct: `OPENSSL_VERSION_NUMBER`) — fixed,
  the code now actually compiles in.

#### R16-B02: License Online Validation MITM
- Added hostname verification via `X509_VERIFY_PARAM_set1_host` and fail-closed
  handling of the verify result.

#### R16-B03: e2e Key Export/Import
- Real implementation: Argon2id KDF + `crypto_secretbox`, atomic file write with
  `0600` permissions, magic header `NCPE2EK1`.

#### R16-B04: ECH HPKE
- Single `OSSL_HPKE_encap` + `OSSL_HPKE_get_public_encap_size` (correct API usage).

#### R16-B05: Certificate Pin Format
- Unified format: lowercase hex SHA-256(SPKI). Base64 pins are converted at load time.

#### R16-B06: probe_resist verify_auth Hardening
- OOB read at `auth_length < 32` fixed (min-length check); added timestamp window
  and replay check.

#### R16-B07: e2e Transcript-Hash Truncation
- A truncated response is now a hard failure (previously bypassed tamper detection).

#### R16-B08: check_memory_integrity
- Real verification: SHA-256 of the obfuscated blob against the baseline.

#### R16-B09: ech_cache Format v2
- v2 format carries all fields (`cipher_suites`, `raw_config`); size caps close
  the OOM-by-`domain_len` vector.

#### R16-B10: create_test_ech_config
- Real keypair generation instead of an all-zero X25519 key.

#### R16-B11: ratchet_dh Protocol Confusion (additional find from tests)
- Strict peer-key size validation (X25519 = 32 bytes, X448 = 56 bytes).

#### R16-B12: identity Rotation Semantics
- Honest semantics for MAC/hostname rotation (mutates the identity, not the OS);
  no more false statistics increments.
